Trasferimento file temporaneo,
cifrato end‑to‑end.

Si apre una stanza dal telefono, si caricano foto e video, si recuperano dal computer scrivendo il codice. I file arrivano identici all’originale e vengono cancellati alla scadenza scelta.

02

Entra con il codice

Sei caratteri, maiuscole e minuscole indifferenti. Si possono incollare in blocco.

  • Nessuna ricompressione

    I byte vengono trasferiti invariati: risoluzione, EXIF e profilo colore restano quelli della fotocamera. Un’impronta SHA‑256 viene verificata al download.

  • Cifratura sul dispositivo

    AES‑256‑GCM con chiave derivata dal codice via PBKDF2. Al server arriva solo un hash del codice: contenuti e nomi dei file restano illeggibili.

  • Cancellazione automatica

    Ogni stanza registra la propria scadenza alla creazione e si cancella da sola quando la raggiunge. I singoli file si possono rimuovere prima.
